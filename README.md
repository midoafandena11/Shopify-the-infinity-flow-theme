# Infinity Flow

A Shopify theme where shoppers add products by **dragging them onto a floating cart**.

- Drag & drop add-to-cart with a visible "+" fallback (keyboard / screen reader friendly)
- Real `<form action="/cart/add">` per product card, so pixels and apps that watch the add request keep working
- Arabic (RTL) and English storefront strings; add more under `locales/`
- Settings: Theme settings → Infinity Flow (cart position, hint, haptics, accent colors)
